<h1>Tembea Kenya 🇰🇪</h1>

<h2>Project Description</h2>

<p>Tembea Kenya is a tourism website designed to showcase Kenya’s beautiful destinations, cultural heritage, wildlife, and tourist attractions.

The website provides visitors with information about different destinations and encourages them to explore Kenya.</p>

<h2>Objectives</h2>
<ul>
<li> Showcase Kenya’s tourist destinations.</li>
<li>Promote local tourism.</li>
<li>Provide accessible information about attractions.</li>
<li>Create a simple and user-friendly browsing experience.</li>
</ul>

<h2>Features</h2>
<ul>
<li>Home Page: Introduction to Tembea Kenya.</li>
<li>Destinations Page: Information about tourist destinations.</li>
<li>About Page: Background and purpose of the project.</li>
<li>Contact Page: Contact information for visitors..</li>
</ul>

<h2>Technologies Used</h2>
<ul>
<li>HTML only</li>
